# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on the
repository's **Security** tab, and include the steps to reproduce. You will get a reply within a few days.

## What the extension can access

It runs on `web.whatsapp.com` and stores a few settings in `chrome.storage.local`. It can also reach
`www.youtube-nocookie.com` and `*.tiktok.com`, only to import a link you paste. See [PRIVACY.md](PRIVACY.md).
