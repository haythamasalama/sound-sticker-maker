# Changelog

## Unreleased

### Added

- Engine: sound stickers from a video, GIF or picture plus any sound, as an animated WebP under 1 MB and Ogg Opus.
- Engine: reads WebM recordings that report no duration.
- Extension: a panel in WhatsApp Web to pick, trim, preview, send or forward sound stickers, in Arabic and English.
- Extension (GitHub version): import a part of a YouTube video without opening a tab, or a TikTok video.
- Website with an online maker that runs in the browser.
- MCP server and agent skill so AI assistants can make sound stickers, with a one-click Claude Desktop installer.
- Six languages: English, Arabic, Spanish, Portuguese, Indonesian and Hindi.
